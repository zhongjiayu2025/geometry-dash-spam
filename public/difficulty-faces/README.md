# Difficulty reference artwork

These twelve PNGs depict Geometry Dash difficulty icons, used for identification
and comparison in the difficulty-face reference page. Game artwork belongs to
RobTop Games. GeometryDashSpam.cc is an independent fan site and does not claim
ownership, an official affiliation, or a new open-source license for these sprites.

Asset archive: https://github.com/tzt345/GDBrowser/tree/master/assets/difficulties
Retrieved using the GitHub file API; original filenames retained. The generic
Demon icon and Hard Demon icon intentionally share the same sprite.
